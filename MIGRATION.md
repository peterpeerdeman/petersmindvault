# Quartz v4 → v5 migration

Tracks every customisation of the v4 fork (branch `main`, last commit `654ef5e`) and what
happened to it on the `v5` branch (based on upstream `v5`, Quartz 5.0.0).

Status: ✅ done · 🔁 superseded by upstream · ❌ dropped · ⏳ open

## Top priority: only `publish: true` notes are published

| #   | Item                                                                   | Status | Notes                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| --- | ---------------------------------------------------------------------- | ------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 0   | `ExplicitPublish` filter (only notes with `publish: true` frontmatter) | ✅     | `@quartz-community/explicit-publish` enabled **and** our own `StrictExplicitPublish` filter (`custom/publish.ts`); the build aborts unless both are active (the v5 plugin loader only logs plugin load failures, which would publish everything). `canvas-page`, `bases-page` and `encrypted-pages` disabled: canvas/bases pages read files from disk and bypass filters. `npm run test:publish` builds `custom/publish-fixture` (published, unpublished, `publish: false/yes`, `Publish:` key, drafts, embeds, tags, aliases, ignored folders, canvas/base/txt files) and fails on any leak. |

Known, unchanged from v4: a published note linking to an unpublished note shows a dead link with the
target's slug (e.g. `./secret-note`), and embeds of unpublished notes render as an empty
"Transclude of secret-note" box. No content, title, tags or description leaks. Every file in
`attachments/` is copied, whether or not a published note uses it.

## Other v5 changes to be aware of

- **URLs are lowercased** (`People/Foo.md` → `/people/foo`). `alias-redirects` (enabled) emits redirect
  pages for the old mixed-case URLs, and Netlify lowercases URLs anyway.
- New plugins kept from the v5 defaults: breadcrumbs, reader mode, darkmode, search, graph, backlinks,
  TOC, folder/tag pages, RSS + sitemap, unlisted pages, note properties (view hidden).
- Upstream GitHub workflows only run on `jackyzha0/quartz`, so they do nothing on this fork.
